# Вклад в XPlink

Одна задача — отдельная ветка и PR; основную ветку не переписывать. Сначала изучить `AGENTS.md` и `docs/PROJECT_MAP.md`. Код на строгом TypeScript, UI без Matrix-бизнес-логики, adapter без React. После изменения исходников обновить `scripts/file-manifest.json` и тесты. Следовать `docs/TEST_PLAN.md` и обязательно сообщать о рисках. Публичный issue для уязвимостей **не использовать**.
