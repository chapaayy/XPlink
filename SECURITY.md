# Security Policy

**Pre-release / stage 1 only.** Никаких обещаний, что система безопасна для реальных чувствительных данных. Не открывайте dev-Compose в интернет, не публикуйте access tokens и `.env`.

Чтобы сообщить об уязвимости, используйте **GitHub Private Vulnerability Reporting** (в настройках Security репозитория при доступности) либо приватный канал владельца репозитория. Не публикуйте exploit-details и секреты в публичных issues.

Модель угроз: `docs/SECURITY_MODEL.md`; lifecycle ключей: `docs/KEY_LIFECYCLE.md`; incident runbook: `docs/runbooks/INCIDENT.md`.
