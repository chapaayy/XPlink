# Продукт

XPlink — приватный чат с собственным UI для сообщества из 10–100 человек. Этап 1 — подтверждение технической безопасности базового текстового канала, а не аналог Discord по функциям. Пространства, роли, медиа, вызовы, видео и PWA откладываются согласно ROADMAP. Не делаем криптографические обещания, превосходящие фактически проверенное.
