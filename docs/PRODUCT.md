# Продукт XPlink — этапы 1–3

XPlink — приватный веб-мессенджер для 10–100 пользователей с собственным Discord-подобным интерфейсом. Это Matrix-клиент с E2EE, а не собственный сервер шифрования.

## Третий этап — текстовый продукт

- **Пространства** — приватные комнаты типа `m.space`, образующие верхний уровень навигации.
- **Категории** — вложенные пространства через `m.space.child` / `m.space.parent`, чтобы группировать каналы.
- **Каналы** — отдельные приватные комнаты с обязательным `m.room.encryption`; приглашения через Matrix membership.
- **Личные сообщения** — зашифрованные комнаты с `is_direct` и персональным `m.direct` account data.
- **Реакции** — стандартное `m.reaction`, передаваемое как E2EE-событие.
- **Вложения** — файлы до 10 МБ, AES-CTR v2 по стандартному протоколу Matrix через Matrix.org библиотеку, SHA-256 шифротекста до расшифровки; загрузка на Synapse только ciphertext.
- **Роли/право писать** — server-enforced Matrix power levels в каждом E2EE-канале. См. `PERMISSIONS.md`.

**Не входит в этап:** полная Discord-модель наследуемых серверных ролей, темы/треды, голос/видео, генерация превью медиа, публичный федеративный деплой, PWA и security audit. Spaces и их названия/участники являются серверными метаданными и **не шифруются E2EE**. Все сообщения/файлы остаются client-side encrypted, при исправной криптографии и доверенном браузерном JS.

## Этап 4: realtime (план и реализация)

Голосовая комната — отдельная приватная Matrix E2EE-комната с `io.xplink.voice` state event. В комнатах появляются действия начать голосовой/видеозвонок. Official Element Call управляет микрофоном, камерой, screen share и состоянием участия, а `rtc-adapter` запрещает старт без подтверждённого Rust Crypto E2EE, членства и объявленного LiveKit. Групповые звонки работают через локальный SFU и JWT appservice. До полного прохождения медиа E2E не считать функциональность принятой.

## Этап 5 — UX и PWA

Мобильный интерфейс в двух режимах (список каналов, содержимое чата), клавиатура и reduced-motion. Manifest позволяет устанавливать приложение в поддерживаемом браузере. Offline fallback **не хранит и не показывает** приватную переписку. Уведомления активны только по разрешению пользователя, при открытой фоновой вкладке, без имён и текстов. Фоновый push при полностью закрытом приложении пока не реализован.
