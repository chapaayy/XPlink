# Этап 5 — адаптивность и доступность

- На ширине до 780 px XPlink показывает rail + список каналов либо rail + чат. Смена режима происходит при выборе комнаты, кнопка «Назад к каналам» возвращает список.
- На широком экране обе панели открыты. Безопасность/права на мобильном открываются вместо чата и закрываются Esc или кнопкой «Закрыть».
- Для клавиатуры есть skip-link, фокус на заголовке выбранной комнаты, `aria-current` для канала, `aria-pressed` для пространства и крупные touch targets.
- `prefers-reduced-motion` отключает плавные переходы и анимации. Используется `100dvh`, чтобы учесть виртуальную клавиатуру и chrome мобильного браузера.
- Требуется реальная проверка Android Chrome и iOS Safari (добавление на главный экран, клик/фокус, виртуальная клавиатура, TalkBack/VoiceOver), 320–1440 px, контрастность и WCAG 2.2 AA. Это не заменяется Playwright в Chromium.
- Уведомления пользователь включает вручную; они отображают только общий текст, без текста E2EE. Нет фонового push после закрытия приложения.
