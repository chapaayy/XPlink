# ADR 0005 — Восстановление ключей принадлежит пользователю

- Статус: принято для реализации этапа 2, подтверждение E2E обязательно
- Дата: 2026-11-04

**Контекст:** без ключа восстановления потеря браузера может сделать историю недоступной, а серверные backup-снимки сами по себе не дают криптографического доступа.

**Решение:** только Matrix Rust Crypto секретное хранилище, cross-signing, стандартный key backup. Клиент показывает recovery key и требует сохранения вне сервиса. Приватный ключ хранится лишь временно в памяти; backend не принимает его ни под каким видом. Подмена существующих cross-signing keys и reset key backup без осознанного подтверждения запрещены.

**Последствия:** если ключ утрачен и доверенных устройств не осталось, восстановление прошлой истории может оказаться невозможным. Никаких обещаний «админ сможет восстановить». Криптографическая безопасность системы шире, чем этот ADR, и требует аудита.
