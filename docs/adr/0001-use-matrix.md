# ADR-0001: Matrix, а не собственный crypto/chat protocol

Статус: принят. XPlink использует matrix-js-sdk с Rust Crypto/WASM, Synapse и PostgreSQL. Для 10–100 участников риск самописных E2EE и multi-device существенно больше, чем инфраструктурная стоимость Matrix. React не занимается криптографией; backend получает только ciphertext и метаданные. За счёт этого мы не можем честно обещать защиту от вредоносного веб-клиента, поставленного самим сервером.
