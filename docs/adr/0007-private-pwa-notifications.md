# ADR 0007 — Приватная PWA и уведомления без контента

- Статус: принято для реализации этапа 5, приёмка ожидает CI
- Дата: 2026-11-04

**Проблема:** installable PWA и нативные уведомления потенциально копируют защищённые данные в CacheStorage и на экран блокировки.

**Решение:** SW перехватывает только same-origin navigate GET, всегда network-first; offline fallback — статический /offline.html, CacheStorage содержит только эту страницу и два публичных PNG. Никакого E2EE offline кеша. Notification API запускается только после клика пользователя и выдаёт только title XPlink + общий текст «Новое зашифрованное сообщение», если вкладка скрыта, сообщение свежее/входящее/расшифрованное/E2EE и пользователь разрешил. Без серверного push.

**Альтернативы:** push payload с plaintext, серверная расшифровка, caching сообщений для офлайна — отвергнуты из-за угроз конфиденциальности.

**Последствия:** после закрытия вкладки уведомлений нет; офлайн-переписка недоступна. Название приложения может появиться на экране блокировки. HTTPS/CSP и security audit остаются этапом 6.
